# UWP host guide

Press **View + Menu** (Back + Start) together on a connected Xbox controller to
open the Blades host guide, including while a game is running. Release both
buttons before using the shortcut again. The shortcut waits while another
dialog is active.

The guide provides Friends and Sessions, Profiles, Network Settings, Network
Status, and Gamerpic Browser. Session browsing uses the currently running title.
Selecting an entry closes the guide and opens its existing netplay/profile
window. Press **B** or use **Close** to return to the game; **Escape** also works
with a keyboard. Back inside a child popup closes that popup first.

The game stays running, and guest controller input is suppressed while host UI
is active. The controller that opens the guide also controls it. This shortcut
is specific to UWP and does not change the desktop hotkey configuration.
